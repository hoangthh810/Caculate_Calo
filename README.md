# Tính Calo Giảm Cân

Mở `index.html` bằng trình duyệt là dùng được, không cần cài đặt hay đăng nhập. Dữ liệu lưu trong trình duyệt (localStorage).

- Nhập cân nặng, số kg muốn giảm, số ngày -> calo nên ăn mỗi ngày
- Ghi món đã ăn kiểu `100g cơm` -> trừ vào calo còn lại hôm nay
- Tick món mua/ăn được -> thực đơn 7 ngày + gợi ý món dễ mua

Test: `node test.js`
